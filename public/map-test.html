Map

Turn on the grid, then change this until the grid lines up with the squares printed on the map. One square is 5 ft.

Give the day and night maps of one place the same group name and different version names. A Day/Night switch then appears in the top left of the map.

Tool

Use the Pins tool: click empty ground to add a pin with the name above, or drag a pin to move it (all pins show while this tool is selected). Every battle map needs a pin named "start" (npm run check fails without one). Other pins are places the AI can send the party to, such as a back door; the AI is told their names. Saved with the map, so the players never need to see it to place themselves.
