Map Test

Check walls, doors, line of sight and fog of war on any map before using it at the table.

Map

Fog and sight

Terrain: choose the Terrain tool above the map and drag a rectangle over difficult ground (right-click inside one to remove it).

Place settings

Turn on the grid, then change this until the grid lines up with the squares printed on the map. One square is 5 ft.

Give the day and night maps of one place the same group name and different version names. A Day/Night switch then appears in the top left of the map.

Pins

Use the Pins tool: click empty ground to add a pin (it opens a card to name it), click a pin to rename it, add a note for the DM or remove it, or drag a pin to move it (all pins show while this tool is selected). Every battle map needs a pin named "start" (npm run check fails without one). Other pins are places the AI can send the party to, such as a back door; the AI is told their names. Saved with the map, so the players never need to see it to place themselves.

Module areas: drag a number onto the map to drop its pin (a ✓ means it is placed; drag it again to move it, or right-click the pin to remove it). The AI reads these to know where each area is.
