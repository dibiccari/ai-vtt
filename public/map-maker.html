Map Maker

Make a new map in a few steps: pick the type, describe it (type, speak, or let the AI surprise you), check the layout, have it painted, and save it. It opens in Map Test ready to edit.

    One square is 5 feet. Bigger maps cost more to design and are painted with smaller squares, so very large ones look softer.
